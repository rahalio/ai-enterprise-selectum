# Selectum — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Head of Sourcing

- As sourcing lead, I want providers scored on orchestration and use-case depth, so that Winner’s Circle marketing cannot replace evidence.
- As sourcing lead, I want aged PoCs escalated, so that toe-dip culture has a cost.

### IA programme owner

- As IA owner, I want Triple-A lever and intersection targets on every engagement, so that AI, automation, and analytics stop being separate contracts that never meet.
- As IA owner, I want bolt-on vs transformative intent explicit, so that we do not over-claim.

### Process owner

- As a process owner, I want conversational projects to define execution completion, so that bots that cannot finish a case are not called successful.
- As a process owner, I want vertical reference assets, so that I can judge transferability.

### Architect

- As architect, I want mega-ISV dependencies visible, so that ecosystem bets are conscious.
- As architect, I want data-centric readiness scored, so that scale SOWs do not assume “throw ML at the lake.”

### Commercial / finance

- As commercial, I want industrialized vs project-centric flagged, so that TCO models differ correctly.
- As finance, I want cost per scaled use case, so that >100% market growth narratives do not excuse unit economics.
